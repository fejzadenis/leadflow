Check a workflow before you send it to anyone

Free, in the browser, nothing uploaded: paste a workflow JSON into the audit tool and ten mechanical checks run — open webhooks, credentials in node fields, missing retries, writes with no de-duplication, expressions pointing at nodes that were renamed.   • Open-ended retainers before a first build. One workflow at a fixed price first; if it goes well, we can talk about a monthly block after that.

Questions people ask before hiring an n8n developer

Cloud or self-hosted?

Both. The difference is credentials and storage: on Cloud you attach credentials through the UI and can use Data Tables, on self-hosted you point at Postgres. I test on a real instance; if you are on Cloud I will tell you where a Data Table beats a Sheets workaround, and if you are on Postgres you get the schema.

How do you handle a job that needs a custom node?

If the API cannot be reached with the HTTP Request node and a Code node, it needs a custom node, which is not a $450 job. I will say so in the quote rather than discover it at hour 60. Most integration work never gets there.

What if my data is sensitive?

Send a shape, not the data: column names, three synthetic rows, and the edge cases. If the job genuinely needs your rows, I will offer to work under an NDA and delete the copy afterwards, and say plainly what access is needed.

What if it breaks later?

Two weeks of fixes included from handover, for defects in what I delivered. Not for a changed API or a new requirement, which is a new quote, and I say which is which before starting.
