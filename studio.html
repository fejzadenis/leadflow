Questions people ask before pasting a list

Is this CSV repair free? Yes - it runs in the tab with no account and no sign-up. The $49 offers are different things: one export fixed by a person (up to 5,000 rows, 24h, a report), or the n8n pack that does this inside your own automation with Sheets logging.

Does it upload my list anywhere? No. There is no fetch, no XHR, no storage - the file is read in this tab and disappears when you close it.

Does it remove duplicate emails? Yes, by email identity: Marko.Petrovic@Acme.com and marko.petrovic@acme.com are one person, and the row with more filled fields is the one kept. The report states how many rows were merged.

Why does my Excel CSV open with question marks or broken letters? The file was saved in a legacy encoding (Windows-1250 on a Serbian/Polish/Czech Windows, Windows-1252 in the West) and was then read as UTF-8. This page decodes the bytes by their real encoding instead of guessing, names the encoding it used, and downloads the cleaned CSV with a BOM so Excel reopens it with the names intact. It also reverses the damage in the other direction - text some tool read as GB18030 (the default on a Chinese Windows, and the bug in n8n's HTTP Request node), where é is stored as a CJK character - because those bytes are still in the cell too.

Which exports does it read? Comma, semicolon and tab separated, including a straight paste from Excel or Google Sheets; Pipedrive Email - Work, HubSpot Work Email and Mailchimp Email 1 headers are recognised.

Does it tell me which addresses will bounce? No - it cleans, it does not verify. Guessed patterns are candidates you confirm before sending, and every rejected row is listed with the rule that rejected it rather than being dropped silently.

Honest limits: patterns are candidates, not verified addresses - you confirm each one before sending. Nothing is sent and nothing is stored; closing the tab discards everything. This tool dedupes inside one file only - it does not read rows already in a spreadsheet. The draft text is a template, not AI.
